# Джарвис

Голосовой помощник для Windows. Слушает слово «Джарвис», понимает речь прямо на вашем компьютере, думает через
Hermes Agent и отвечает голосом Microsoft. Работает как обычное
приложение: окно с настройками, значок в трее, запуск вместе с Windows, обновления в один клик.

## Установка

1. Скачайте **[Jarvis-Setup.exe](https://github.com/kitlame7-lab/jarvis67/releases/latest/download/Jarvis-Setup.exe)**
   и запустите. Права администратора не нужны.
2. Оставьте флажок «Запускать вместе с Windows». Джарвис появится в трее.
3. Откройте окно, раздел **Модель**, выберите **«Свой сервер»** и введите три поля: `Base URL`, `API Key`, `Model`.
   Нажмите **«Сохранить и проверить»**.
4. Скажите: «Джарвис, какая погода».

Нужно заранее: Windows 10 или 11, установленный Hermes Agent, микрофон и интернет (голос, погода и курсы работают онлайн).
Первый запуск скачивает модель распознавания речи (около 500 МБ), это происходит один раз.

Старая версия из папки на рабочем столе заменится сама: установщик закроет её, уберёт ярлык из «Автозагрузки» и перенесёт
ваши настройки.

## Что внутри окна

| Раздел | Для чего |
|---|---|
| Главное | Состояние, пауза, перезапуск, последний разговор, автозапуск |
| Модель | Провайдер, ключ, **свой сервер (Base URL + ключ + модель)**, проверка |
| Голос | Нейроголос Microsoft, скорость, высота, прослушивание, как к вам обращаться |
| Слух | Микрофон, модель распознавания, слова вызова |
| Возможности | Город для погоды, игровой режим, свои программы, права |
| Telegram | Токен бота, разрешённые ID, перезапуск шлюза Hermes |
| Чат | То же самое текстом |
| Журнал | Что происходило внутри |
| Система | Проверка всей цепочки, обновления, навык для Hermes |

## Своя модель с сайта-перепродавца

Любой сервер, совместимый с OpenAI, подключается тремя значениями. Приложение записывает их в сам Hermes
(`config.yaml` и `.env`), поэтому они работают и в голосе, и в Telegram, и в консоли Hermes.

- **Base URL** обычно заканчивается на `/v1`. Если вставить адрес целиком вместе с `/chat/completions`, лишнее отрежется.
- **Model** пишется ровно так, как его называет сервер. Кнопка «Показать модели сервера» подскажет список.
- Ключ хранится в `.env` Hermes и в окне показывается только последними четырьмя символами.

Запросы к такой модели идут через сервер продавца, он технически может их читать. Не диктуйте пароли и личные данные.

## Голос

Джарвис говорит нейроголосами Microsoft (те же, что в Edge): бесплатно, без ключа, по-русски. При сбое сети
включается обычный голос Windows. ElevenLabs больше не используется.

[VibeVoice](https://github.com/microsoft/VibeVoice) от Microsoft не подошёл: у него нет русского языка, а модели
с открытыми весами рассчитаны на исследования и требуют видеокарту. Если Microsoft добавит русский, голос можно будет
заменить, не трогая остальное: вся озвучка собрана в классе `Speaker` в `jarvis/core.py`.

## Telegram

Бот работает через шлюз Hermes. В разделе «Telegram» вставьте токен от @BotFather и свой числовой ID (его покажет
@userinfobot), нажмите «Сохранить и перезапустить шлюз». Без списка ID бот никому не отвечает.

## Обновления

Приложение раз в шесть часов смотрит последний релиз в этом репозитории. Если версия новее, сверху появляется
плашка «Установить»: оно скачивает установщик, сверяет контрольную сумму, ставит поверх и запускается заново.
Настройки лежат отдельно (`%APPDATA%\Jarvis`), обновление их не трогает. Отключить проверку можно в разделе «Система».

## Для разработчика

```bash
pip install -r requirements.txt -r requirements-dev.txt
python -m jarvis            # запуск из исходников
python -m pytest -q         # тесты (окно проверяется без экрана)
```

Выпуск новой версии:

1. Поднять `__version__` в `jarvis/__init__.py` и закоммитить.
2. Поставить тег `vX.Y.Z` и отправить его: `git tag v3.0.1 && git push origin v3.0.1`.
3. Действие `Release` соберёт приложение и установщик на Windows, проверит сборку и выложит `Jarvis-Setup.exe`
   в Releases вместе с контрольной суммой. Если сборка упала, в репозитории появится задача с хвостом журнала.

Устройство:

```
jarvis/
  core.py        слово вызова, Hermes, распознавание речи, голос, микрофон, диалог, самопроверка
  backend.py     настройки, ключи и модель Hermes, свой сервер, автозапуск, навык
  service.py     жизненный цикл ассистента (без Qt)
  updater.py     обновления из GitHub Releases
  gui/           окно, страницы, трей, тема
  resources/     навык jarvis-pc для Hermes (погода, курсы, окна, таймер, игровой режим)
tools/           jarvis-pc.exe и генератор значка
packaging/       PyInstaller и Inno Setup
tests/           160+ проверок
```

Данные пользователя: `%APPDATA%\Jarvis` (настройки, журнал, кэш). Ключи: `%LOCALAPPDATA%\hermes\.env`.
