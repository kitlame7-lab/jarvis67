# Джарвис

Голосовой помощник для Windows. Слушает слово «Джарвис», понимает речь прямо на вашем компьютере, думает через
Hermes Agent и отвечает голосом Microsoft. Работает как обычное
приложение: окно с настройками, значок в трее, запуск вместе с Windows, обновления в один клик.

## Установка

1. Скачайте **[Jarvis-Setup.exe](https://github.com/kitlame7-lab/jarvis67/releases/latest/download/Jarvis-Setup.exe)**
   и запустите. Права администратора не нужны.
2. Оставьте флажок «Запускать вместе с Windows». Джарвис появится в трее.
3. Откройте окно, раздел **Подключения**, выберите **«Свой сервер»** и введите три поля: `Base URL`, `API Key`, `Model`.
   Нажмите **«Сохранить и проверить»**.
4. Скажите: «Джарвис, какая погода».

Нужно заранее: Windows 10 или 11, установленный Hermes Agent, микрофон и интернет (голос, погода и курсы работают онлайн).
Первый запуск скачивает модель распознавания речи (около 500 МБ), это происходит один раз.

Старая версия из папки на рабочем столе заменится сама: установщик закроет её, уберёт ярлык из «Автозагрузки» и перенесёт
ваши настройки.

## Что внутри окна

| Раздел | Для чего |
|---|---|
| Главное | Состояние, полоса загрузки, пауза, поле «Написать Джарвису», последний разговор, автозапуск |
| Задачи | **Запись действий** и список записанных задач: запустить, посмотреть шаги, удалить |
| Голос | Нейроголос Microsoft, скорость, высота, прослушивание, как к вам обращаться |
| Слух | Микрофон, модель распознавания, слова вызова |
| Возможности | Город для погоды, игровой режим, свои программы, права |
| Подключения | Модель (провайдер, ключ, **свой сервер: Base URL + ключ + модель**) и Telegram-бот |
| Диагностика | Находит причину сбоя, подсказывает что делать, отправляет отчёт разработчику; журнал |
| Система | Проверка всей цепочки, обновления, навык для Hermes |

## Научить Джарвиса задаче

Скажите: **«Джарвис, запомни как я это делаю»** (или нажмите «Начать запись» в разделе «Задачи»). Выполните действия
на компьютере как обычно и скажите **«стоп»**. Джарвис соберёт задачу из ваших щелчков, нажатий клавиш и смены окон,
сам придумает название и фразы вызова. Потом достаточно сказать **«Джарвис, выполни задачу отчёт по продажам»**.

- Во время записи значок в трее красный; слушается только «стоп» и «отмена записи». Запись сама остановится через 10 минут.
- Повтор можно прервать клавишей **Esc**.
- Текст, набранный в окнах с паролями и входом, **не сохраняется**; на таком шаге повтор останавливается, и пароль вводите вы.
- Нейросеть получает описание шагов без набранного текста и может только назвать задачу и убрать случайные щелчки.
  Шаги она не придумывает и не меняет.
- Щелчки запоминаются относительно окна, поэтому сдвинутое окно не мешает. Если окно сильно изменилось, нажатие
  идёт по положению на экране, и об этом сказано в итоге.
- Задачи лежат в `%APPDATA%\Jarvis\tasks`, снимки экрана при щелчках видны рядом с задачей.

## Как Джарвис отвечает (скорость и надёжность)

Раньше каждый вопрос запускал Hermes как отдельную тяжёлую программу: ответ шёл десятки секунд, а один зависший вызов
блокировал все следующие. Теперь три уровня:

1. **Быстрые команды без нейросети** — «который час», «громче», «потише», «сверни окна», «открой блокнот», «скриншот»,
   курс валюты и погода выполняются сразу (доли секунды).
2. **Встроенный движок** — остальное уходит одним прямым запросом к вашей модели (тот же адрес, ключ и модель из
   «Подключений»). Если нужно действие на компьютере, модель просит команду, Джарвис выполняет её через `jarvis-pc`
   и возвращает результат. Опасные команды (форматирование диска, системные процессы и папки) блокируются.
3. **Hermes** — запасной путь для провайдеров, которых встроенный движок не знает (например, Anthropic).

Выбор — в «Подключения → Движок ответов» (Авто / Встроенный / Только Hermes). Каждый запрос считается в отдельном
потоке с жёстким пределом времени (по умолчанию 100 с), поэтому зависший ответ не мешает следующему, а «Остановить»
обрывает ожидание и речь сразу, и повторный запуск проходит без задержки. Зависший Hermes завершается вместе с дочерними
процессами. Время последних ответов видно в «Диагностике»; если они медленные, она подскажет, что сделать.

## Если что-то не работает

Раздел **«Диагностика»** проверяет сеть (Hugging Face и его зеркало, голос Microsoft, GitHub, ваш сервер модели),
модель речи, микрофон, место на диске и Hermes, и на каждую находку пишет, что делать. Кнопка **«Сообщить разработчику»**
открывает готовое обращение на GitHub, а полный отчёт (ключи и имя пользователя в путях скрыты) кладёт в буфер обмена.

Модель распознавания речи скачивается с видимой полосой на главной; если Hugging Face недоступен, берётся зеркало.
Модель можно положить вручную в `%APPDATA%\Jarvis\models\small`.

## Своя модель с сайта-перепродавца

Любой сервер, совместимый с OpenAI, подключается тремя значениями. Приложение записывает их в сам Hermes
(`config.yaml` и `.env`), поэтому они работают и в голосе, и в Telegram, и в консоли Hermes.

- **Base URL** обычно заканчивается на `/v1`. Если вставить адрес целиком вместе с `/chat/completions`, лишнее отрежется.
- **Model** пишется ровно так, как его называет сервер. Кнопка «Показать модели сервера» подскажет список.
- Ключ хранится в `.env` Hermes и в окне показывается только последними четырьмя символами.

Запросы к такой модели идут через сервер продавца, он технически может их читать. Не диктуйте пароли и личные данные.

## Голос

Джарвис говорит нейроголосами Microsoft (те же, что в Edge): бесплатно, без ключа, по-русски. При сбое сети
включается обычный голос Windows. ElevenLabs больше не используется.

[VibeVoice](https://github.com/microsoft/VibeVoice) от Microsoft не подошёл: у него нет русского языка, а модели
с открытыми весами рассчитаны на исследования и требуют видеокарту. Если Microsoft добавит русский, голос можно будет
заменить, не трогая остальное: вся озвучка собрана в классе `Speaker` в `jarvis/core.py`.

## Telegram

Бот работает через шлюз Hermes. В разделе «Подключения» вставьте токен от @BotFather и свой числовой ID (его покажет
@userinfobot), нажмите «Сохранить и перезапустить шлюз». Без списка ID бот никому не отвечает.

## Обновления

Приложение раз в шесть часов смотрит последний релиз в этом репозитории. Если версия новее, сверху появляется
плашка «Установить»: оно скачивает установщик, сверяет контрольную сумму, ставит поверх и запускается заново.
Настройки лежат отдельно (`%APPDATA%\Jarvis`), обновление их не трогает. Отключить проверку можно в разделе «Система».

## Для разработчика

```bash
pip install -r requirements.txt -r requirements-dev.txt
python -m jarvis            # запуск из исходников
python -m pytest -q         # тесты (окно проверяется без экрана)
```

Выпуск новой версии:

1. Поднять `__version__` в `jarvis/__init__.py` и отправить в `main`.
2. Если релиза с таким номером ещё нет, действие `Release` соберёт приложение и установщик на Windows, проверит сборку
   и выложит `Jarvis-Setup.exe` в Releases вместе с контрольной суммой (тег `vX.Y.Z` создастся вместе с релизом).
   Если сборка упала, в репозитории появится задача с хвостом журнала.

Перед отправкой полезно запустить анализатор кода: `python tools/doctor.py` (в CI он обязателен). Он находит то, что
не ловят тесты: сетевые вызовы и запуск программ без времени ожидания, текстовые файлы без кодировки, вечные ожидания,
подстановку данных в PowerShell, расхождение навыка и `pc.py`. Исключение для осознанного случая:
`# doctor: ok(правило)` с объяснением. `--deep` добавляет проверку типов (mypy).

Устройство:

```
jarvis/
  core.py        слово вызова, Hermes, распознавание речи, голос, микрофон, диалог, самопроверка
  llm.py         прямой запрос к модели по протоколу OpenAI (без Hermes)
  agent.py       встроенный движок: цикл «модель → команда ПК → результат», защита от опасных команд
  quick.py       быстрые команды без нейросети
  backend.py     настройки, ключи и модель Hermes, свой сервер, автозапуск, навык
  service.py     жизненный цикл ассистента (без Qt): загрузка модели, сторож, запись и запуск задач
  models.py      скачивание модели речи: полоса, зеркала, отмена, ручная папка
  diag.py        диагностика: сбор состояния, правила «причина → что делать», отчёт
  trace.py       события записи → шаги задачи (чистая логика)
  winio.py       чтение мыши, клавиш и окон Windows (опрос, без хуков)
  teach.py       рекордер: запись, снимки, сборка задачи, разметка нейросетью
  tasks.py       хранилище записанных задач
  intents.py     голосовые команды самого Джарвиса (запись, запуск задачи)
  updater.py     обновления из GitHub Releases
  gui/           окно, страницы, трей, тема
  resources/     навык jarvis-pc для Hermes (погода, курсы, окна, таймер, игровой режим)
tools/           doctor.py (анализатор кода), jarvis-pc.exe, генератор значка
packaging/       PyInstaller и Inno Setup
tests/           380+ проверок
```

Данные пользователя: `%APPDATA%\Jarvis` (настройки, журнал, кэш). Ключи: `%LOCALAPPDATA%\hermes\.env`.
